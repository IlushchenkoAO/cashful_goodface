# Cashful Dashboard prototype: checklist against the Goodface review (12.10.2026)

- [x] **Remove the profile photo option.**
  There is no photo upload in Personal or Developer. Avatars show initials everywhere.

- [x] **One user: a Personal account and several Developer accounts.**
  - Built as an account menu at the bottom of the sidebar, as in the mockup.
  - The menu holds the list of accounts, "Create developer account", User settings and Logout.

- [x] **Separate user settings and account settings.**
  - It is one Settings page with a navigation on the left in two groups: Account settings and User settings.
  - "User settings" in the account menu opens the Profile section.

- [x] **SDK rules before the password at Developer sign-up.**
  - A step with the three rules, illustrated, and an "I agree / I understand" button.
  - It is shown every time, including when creating another developer account.

- [x] **Create App: platform as multiple select.**
  Platforms are chosen with checkboxes.

- [x] **Create App: Application ID and Application Release ID at draft stage.**
  - Both IDs are issued as soon as the app is created. There is one Release ID per app.
  - The SDK installation note is shown until the app is Active.

- [x] **Payouts: collect billing information.**
  - Collected once (Personal and Developer). It opens on the first payout request and can be edited in Settings.

- [x] **Payouts: SMS code.**
  - A payout is confirmed with a code sent to the phone in Profile.
  - If there is no phone yet, it is asked for on the spot.

- [x] **Multi-account support with roles and team management (requested separately).**
